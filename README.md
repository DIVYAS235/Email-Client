========= EMAIL CLIENT APP ===========

The project "EMAIL CLIENT" is an app which uses CAISY(Central AI System) , built in apps of Project Prophet and GEMINI as backend to generate thhe contents of the emails. 

Email client app uses Natural Language as the primary interface which allows users to control and interact with system features using everyday language ,removing the need to manually configure low-level parameters. 

CAISY(Central AI System):It is an AI-powered client that selscts the appropriate app and generates is metadata(app_hash) using GEMINI and app.json.

 Installed Apps acts as the app launcher for CAISY,dynamically running apps based on the selected app name and passing the app_hash as configuration.
